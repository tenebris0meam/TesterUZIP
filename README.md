# Тестер УЗИП (tester-uzip)

Прошивка настольного тестера устройств защиты от импульсных перенапряжений (УЗИП) на микроконтроллере **STM32F103C8T6**. Тестер подаёт на испытуемый прибор регулируемое высокое напряжение (до 550 В), измеряет напряжение и ток через прецизионный монитор **INA239** и выносит вердикт «исправно / неисправно» по каждой проверке. Результаты отображаются на графическом дисплее **MT-12864B** (контроллер NT75451).
