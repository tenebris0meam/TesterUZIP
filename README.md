# Тестер УЗИП

Тестер УЗИП — автономное устройство для проверки устройств защиты от импульсных перенапряжений (УЗИП).
По форм-фактору близок к мультиметру, но ориентирован на автоматизированную и полуавтоматическую проверку многоканальных линий защиты.

---

## Назначение

Устройство предназначено для:

- проверки состояния УЗИП;
- автоматической коммутации линий при тестировании через RJ45;
- ручной проверки через щупы;
- хранения и использования профилей тестирования, подготовленных на ПК;
- звуковой и визуальной индикации результатов.

---

## Аппаратная часть

### Экран

- Символьный LCD 20×4 фирмы МЭЛТ
- Отображение меню, параметров теста и результатов
- Индикация статуса устройства

---

### Кнопки управления (4 шт.)

Используются для:

- навигации по меню
- запуска теста
- выбора профиля УЗИП
- подтверждения действий

---

### Пищалка (звуковая индикация)

- Подтверждение нажатий
- Сигнализация об ошибке
- Индикация завершения теста

---

### Разъёмы для проверки

Устройство оснащено двумя типами подключения:

#### 1. Щупы

- Ручная проверка
- Диагностика отдельных каналов
- Локальный контроль

#### 2. RJ45

- Проверка многоканальных УЗИП
- Автоматическая коммутация линий
- Подключение:
  - напрямую к устройствам с **RJ45**
  - через переходник **«К1»** для других типов подключений

RJ45 используется для последовательной проверки всех каналов защиты по заданному алгоритму.

---

## Питание

Возможные варианты питания:

- Батарея 9В (тип "Крона")
- Внешний источник 15В DC

Устройство автономно и не требует постоянного подключения к ПК или источнику питания, но для проверки некоторых УЗИП лучше использовать питание 15В DC.

---

## Принцип работы

1. На ПК в специализированной программе [Tester UZIP DDBG](http://gitlab.tah.local/software/tester-uzip-ddbg) формируется файл конфигурации.
2. В файле описываются:
   - тип УЗИП
   - параметры проверки
   - тип подключения (RJ45, К1 или Щупы)
   - последовательность коммутации линий
3. Конфигурация используется устройством при выполнении теста.
4. Устройство:
   - автоматически переключает линии (при RJ45 или К1)
   - выполняет измерение
   - отображает результат на экране
   - подаёт звуковой сигнал
   - сохраняет данные теста

## Структура проекта (прошивка)

Проект реализован на **STM32** (Контроллер **STM32F103C8T6**).
Используется **HAL**
Среда разработки **Keil uVision5**

Основные модули:

- `main` — точка входа
- `system_stm32f1xx` — системная инициализация
- `LCD` — работа с дисплеем
- `keyboard` — обработка кнопок
- `UI` — логика интерфейса
- `measure` — измерительный модуль
- `devices` — описание проверяемых устройств
- `connectors` — логика коммутации линий
- `generators` — генерация сигналов
- `buzz` — управление пищалкой
- `flash` — работа с памятью
- `stm32f1xx_it` — обработчики прерываний
- `stm32f1xx_hal_msp` — инициализация периферии

Архитектура разделена на:

- аппаратный слой (драйверы)
- слой измерений
- UI
- логику тестирования

---

## Особенности

- Автономная работа
- Отсутствие необходимости постоянного подключения к ПК
- Минимальный пользовательский интерфейс (кнопки + LCD)
- Возможность расширения списка поддерживаемых УЗИП через файл конфигурации
