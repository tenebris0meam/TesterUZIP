# Описание состояний Тестера УЗИП

## Инициализация (Init)

Состояние, в котором не должны быть активны кнопки, а дисплей должен показывать процесс инициализации

## Простой (Idle)

Состояние, в котором пользователь настраивает Тестер. Активны кнопки, дисплей показывает список настроек и какие настройки сейчас выбраны. 

## Генерация (Gen)

Состояние, в котором активна только автоматика. Дисплей отображает актуальную информацию о напряжении и токе, а также отображает выбранные настройки.
