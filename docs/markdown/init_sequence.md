
# Подробное описание процесса инициализации Тестера УЗИП

## Аппаратная инициализация STM32

### Отключение интерфейса JTAG

Пины PA15, PB3 и PB4 жёстко привязаны к интерфейсу JTAG, и после выхода из Reset_Handler они оккупированы JTAG'ом. 

Чтобы этого избежать, первые строки должны содержать:  
1. Разрешение тактирования модуля AFIO  

```c
    ...
    LL_APB2_GRP1_EnableClock(LL_APB2_GRP1_PERIPH_AFIO);
    ...
```

2. Полное выключение JTAG

```c
    ...
    LL_GPIO_AF_Remap_SWJ_NOJTAG();
    ...
```

### Инициализация FLASH и RCC

В схеме заложены кварцевые резонаторы ZQ1 и ZQ2, 25 МГц и 32.768 кГц соответственно. 

Тактирование шины SYS должно быть от PLL, source для PLL выбран HSE. PLL приводит тактирование к частоте 60 МГц. 

На AHB и APB2 тактирование равно SYS, для APB1 - 7.5 МГц (SYS/8). 

Wait-cycles для FLASH должны быть равны 2 cycles.
